# notella-plugin

Claude Code plugin marketplace for **notella** — handwritten note intelligence, local-first.

```
/plugin marketplace add worksona/notella-plugin
/plugin install notella@notella-plugin
```

Then `/notella-state init` to create `~/notella/`, drop page photos in `~/notella/inbox/`, and run `/notella-orchestrator`.

Skills: `/notella-actions` · `/notella-classify` · `/notella-composition` · `/notella-daily-synthesis` · `/notella-diagram` · `/notella-first-pass` · `/notella-intake` · `/notella-kanban` · `/notella-metadata` · `/notella-orchestrator` · `/notella-project-synthesis` · `/notella-sketch` · `/notella-state` · `/notella-table` · `/notella-themes` · `/notella-transcribe` · `/notella-weekly-synthesis`

This repo is the canonical source of the notella skills — edit them here, under `notella/skills/`. The app that displays their output is [worksona/notella-desktop](https://github.com/worksona/notella-desktop).
